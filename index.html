ICT Glossary

Network
A collection of interconnected devices that exchange data and share resources with each other.
Cloud Computing
The delivery of computing services over the internet including storage, databases, and software.
Cybersecurity
The practice of protecting systems, networks, and programs from digital attacks and unauthorized access.
Algorithm
A process or set of step-by-step rules to be followed in calculations or problem-solving operations.
Operating System
System software that manages computer hardware, software resources, and provides common services for programs.

Frequently Asked Questions (FAQ)

What is the role of HTML in web development?
HTML provides the fundamental structure and content of a webpage, organizing text, images, links, and multimedia elements.
Why do we use definition lists in web pages?
Definition lists using dl, dt, and dd are used to cleanly group terms with their descriptions or questions with their corresponding answers.
How do audio and video tags work in HTML5?
They allow multimedia files like MP3 and MP4 to play directly inside the browser using simple HTML control features.
What is the difference between hardware and software?
Hardware refers to physical computer equipment, while software consists of code and applications that run on that physical equipment.
How can students practice basic HTML coding?
Students can practice writing HTML using basic text editors like Notepad and viewing their saved code files in any web browser.
